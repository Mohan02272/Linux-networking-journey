Network protocol = Rules for communication between machines

Layer	        Examples
Application	HTTP, FTP, DNS, SMTP, SNMP
Transport	TCP, UDP
Network	        IP
Data Link	MAC

1. HTTP (HyperText Transfer Protocol)

Used for: Web browsing


How it works:

Client (browser) → sends request
Server → sends response

Port:HTTP = 80

2. HTTPS (Secure HTTP)

HTTP + SSL/TLS encryption

HTTPS = 443

3. FTP (File Transfer Protocol)

Used for: Upload/download files from server

Port: 21

4. SFTP (Secure File Transfer Protocol)

Encrypted connection

Port: 22

5. DNS (Domain Name System)

You type domain > DNS server resolves IP

Port - 53

6. DHCP (Dynamic Host Configuration Protocol)

Automatically assigns: IP address,Gateway,DNS

Port: 67

7. SMTP : (Simple Mail Transfer Protocol)

Used for: Sending emails

Port : 25 

8. SNMP : SNMP (Simple Network Management Protocol)

Used for: Monitoring devices

Port: 161
