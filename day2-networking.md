
# SWITCH : A switch connects devices inside the same network (LAN)

How it works : Switch uses MAC address table

Example:

PC1 → MAC A
PC2 → MAC B

If PC1 sends data → switch sends ONLY to PC2.


# ROUTER : A router connects different networks.

How it works: It uses IP addresses + routing table.


# FIREWALLS: A firewall controls traffic based on rules.

How it works: It works on IP or Ports.


# LOAD BALANCER: Distributes traffic across multiple servers.

How it works: User → Load Balancer → Server 1/Server 2/Server 3.


# Access Point: A device that provides wireless connection to network.

How it works : How it works:
Converts wired network → wireless
Devices connect via WiFi
